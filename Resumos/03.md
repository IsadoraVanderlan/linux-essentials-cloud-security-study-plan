# 📖 Guia de Mnemônicos: Comandos e Flags do Linux

## 🛠️ Comandos Principais

- **`pwd`** — **P**rint **W**orking **D**irectory
  - **Print:** Imprimir / Exibir
  - **Working:** De trabalho / Atual
  - **Directory:** Diretório / Pasta
  - 💡 _Tradução mental:_ "Exiba a pasta em que estou trabalhando agora."

- **`cd`** — **C**hange **D**irectory
  - **Change:** Mudar / Alterar
  - **Directory:** Diretório / Pasta
  - 💡 _Tradução mental:_ "Mude para outra pasta."

- **`ls`** — **L**i**S**t
  - **List:** Listar / Mapear
  - 💡 _Tradução mental:_ "Liste o conteúdo desta pasta."

- **`clear`** — **CLEAR**
  - **Clear:** Limpar / Esvaziar
  - 💡 _Tradução mental:_ "Limpe a tela do terminal."

---

## 🚩 Flags e Opções do Comando `ls`

- **`-l`** — **L**ong
  - **Long:** Longo / Detalhado
  - 💡 _Tradução mental:_ "Mostre a listagem no formato longo (com permissões, tamanho e datas)."

- **`-a`** — **A**ll
  - **All:** Tudo / Todos
  - 💡 _Tradução mental:_ "Mostre todos os arquivos, incluindo os ocultos (iniciados com `.`)."

- **`-h`** — **H**uman-readable
  - **Human:** Humano
  - **Readable:** Legível / Fácil de ler
  - 💡 _Tradução mental:_ "Mostre os tamanhos em formato legível para humanos (K, M, G em vez de bytes)."

- **`-la`** — **L**ong + **A**ll
  - 💡 _Tradução mental:_ "Mostre absolutamente tudo no formato longo e detalhado."
- **`-m`** — **M**ode (Commas / Fill)
  - **Commas:** Vírgulas
  - **Fill:** Preenchimento contínuo
  - 💡 _Tradução mental:_ "Liste os arquivos em sequência contínua na horizontal, separados por vírgula ($ ls -m
    arquivo1.txt, arquivo2.txt, pasta1, pasta2)"
- **`-n`** — **N**umber
  - **Number:** Número / Numerar
  - 💡 _Tradução mental:_ "Numere todas as linhas ao exibir o texto."
  - 🧪 _Exemplo:_ `cat -n arquivo.txt`

- **`-o`** — **O**utput
  - **Output:** Saída / Direcionamento
  - 💡 _Tradução mental:_ "Redireciona o resultado de um comando para dentro de um arquivo."
  - 🧪 _Exemplo:_ `comando > arquivo.txt`

- **`-p`** — **P**asta / **P**ath
  - **Path:** Caminho / Indicador de diretório
  - 💡 _Tradução mental (Macete):_ "**P** de **P**asta! Coloca uma barra `/` no final para destacar os diretórios."
  - 🧪 _Exemplo:_ `ls -p`

- **`.`** — **Current Directory** (Diretório Atual)
  - 💡 _Tradução mental:_ "Representa a pasta onde estou posicionado agora."
  - 🧪 _Exemplo:_ `cd .` (continua na mesma pasta) ou `./script.sh` (executa um arquivo local).

- **`~`** — **Home Directory** (Diretório Pessoal)
  - **Home:** Casa / Pasta principal do usuário
  - 💡 _Tradução mental:_ "Atalho universal para a pasta pessoal do usuário (ex: `/home/isadora`)."
  - 🧪 _Exemplo:_ `cd ~`

- **`| less`** — **Pipe + Less** (Paginação)
  - **Pipe (`|`):** Conector / Tubo (envia a saída de um comando para outro).
  - **Less:** Menos / Menos páginas (visualizador rolável).
  - 💡 _Tradução mental:_ "Pegue um texto grande e deixe eu ler pausadamente, rolando a tela para cima e para baixo."
  - 🧪 _Exemplo:_ `cat arquivo_gigante.txt | less`

- **`q`** — **Quit** (Sair)
  - **Quit:** Sair / Fechar
  - 💡 _Tradução mental:_ "Aperte `q` para sair de telas de visualização como o `less` ou manuais."

  ***

## 🛠️ Comandos Principais

- **`pwd`** _(Print Working Directory)_: Exibe o caminho absoluto da pasta atual.
  - _Exemplo:_ `/home/usuario`

- **`cd`** _(Change Directory)_: Navega entre diretórios.
  - `cd ~` ou `cd`: Vai para a pasta do usuário (Home).
  - `cd ..`: Volta uma pasta acima.
  - `cd -`: Volta para a última pasta visitada.
  - `cd /`: Vai para a raiz do sistema.
- **`ls`** _(List)_: Lista o conteúdo da pasta.
  - `ls -l`: Exibe detalhes (permissões, tamanho, data).
  - `ls -a`: Mostra arquivos ocultos (iniciados com `.`).
  - `ls -lh`: Detalhes com tamanho legível (K, M, G).
  - `ls -la`: Combina todos os detalhes e arquivos ocultos.
- **`clear`**: Limpa a tela do terminal (Atalho: `Ctrl + L`).

---

## 💡 Conceitos Rápido

- **Caminho Absoluto:** Começa na raiz `/` (ex: `cd /var/log`).
- **Caminho Relativo:** Parte da pasta atual (ex: `cd documentos`).
- **Símbolos Chave:** `.` (pasta atual) | `..` (pasta pai) | `~` (home).
