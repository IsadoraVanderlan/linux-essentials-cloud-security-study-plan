# Módulo 10: Criação e Alteração de Usuários no Linux

Este módulo aborda os comandos fundamentais do gerenciamento de contas de usuário no Linux: **`useradd`**, **`passwd`** e **`usermod`**.

---

## 📌 1. Criação de Usuários com `useradd` (Aula 36)

O comando `useradd` é um utilitário de baixo nível utilizado para criar novas contas de usuário no sistema.

### **Principais Opções do `useradd`**

- **`-m`**: Cria o diretório pessoal (_home directory_) do usuário em `/home/<usuario>`.
- **`-s <shell>`**: Define o shell padrão do usuário (ex: `/bin/bash` ou `/sbin/nologin`).
- **`-g <grupo>`**: Define o grupo primário (GID) do usuário.
- **`-G <grupo1,grupo2>`**: Adiciona o usuário a grupos secundários/adicionais.
- **`-c "<comentario>"`**: Adiciona uma descrição ou nome completo (campo GECOS).
- **`-d <caminho>`**: Especifica um caminho customizado para o diretório home.
- **`-e YYYY-MM-DD`**: Define uma data de expiração para a conta.

### **Exemplo Prático**

```bash
sudo useradd -m -s /bin/bash -c "Maria Silva" -G sudo,docker maria
```

## 📌 2. Definindo e Gerenciando Senhas com `passwd`

O comando `passwd` permite alterar a senha de um usuário existente e gerenciar parâmetros de segurança da conta.

### **Uso Geral**

- **`passwd`**: Altera a senha do usuário atualmente conectado.
- **`sudo passwd <usuario>`**: Permite ao administrador alterar a senha de qualquer usuário sem precisar da senha antiga.

### **Opções Úteis de Gerenciamento**

- **`-l <usuario>`** (_Lock_): Bloqueia a conta do usuário (insere um `!` no `/etc/shadow`).
- **`-u <usuario>`** (_Unlock_): Desbloqueia a conta do usuário.
- **`-e <usuario>`** (_Expire_): Força o usuário a trocar a senha no próximo login.
- **`-S <usuario>`** (_Status_): Exibe o status da senha da conta.

## 📌 3. Modificação de Usuários com `usermod` (Aula 39)

O comando `usermod` modifica as configurações e propriedades de uma conta de usuário já existente.

### **Principais Opções do `usermod`**

- **`-aG <grupo>`**: **Adiciona** o usuário a grupos secundários sem removê-lo dos grupos atuais (**atenção:** sempre use o `-a` junto com o `-G`).
- **`-s <shell>`**: Altera o shell padrão do usuário.
- **`-l <novo_nome>`**: Altera o nome de login (_username_) do usuário.
- **`-d <novo_caminho> -m`**: Altera o diretório home e move os arquivos existentes para a nova localização.
- **`-L`**: Bloqueia a senha do usuário.
- **`-U`**: Desbloqueia a senha do usuário.

### **Exemplo Prático**

```bash
# Adicionar usuário ao grupo wheel/sudo mantendo os grupos atuais
sudo usermod -aG sudo maria

# Alterar o shell padrão para Zsh
sudo usermod -s /bin/zsh maria
```

## 🛠️ Resumo de Comandos e Boas Práticas

| Comando       | Finalidade Principal                       | Exemplo de Uso                         |
| :------------ | :----------------------------------------- | :------------------------------------- |
| **`useradd`** | Criar novas contas de usuário              | `sudo useradd -m -s /bin/bash usuario` |
| **`passwd`**  | Alterar e gerenciar senhas/status          | `sudo passwd usuario`                  |
| **`usermod`** | Modificar atributos de usuários existentes | `sudo usermod -aG docker usuario`      |

### **⚠️ Dica Importante**

Sempre utilize a flag **`-a`** (append) junto com a flag **`-G`** ao usar o `usermod`. Se você executar `usermod -G grupo usuario` sem o `-a`, o usuário será **removido de todos os outros grupos secundários** dos quais fazia parte!
