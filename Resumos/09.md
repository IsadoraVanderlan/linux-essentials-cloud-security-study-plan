# Módulo 09: Gestão de Usuários e Identidade no Linux

Este módulo aborda como o sistema operacional Linux gerencia as contas de usuários, identidades e senhas através de dois arquivos fundamentais do sistema: `/etc/passwd` e `/etc/shadow`.

---

## 📌 1. O Arquivo `/etc/passwd` (Aula 33)

O arquivo `/etc/passwd` é um arquivo de texto plano acessível para leitura por todos os usuários do sistema (`read-all`). Ele contém as informações essenciais das contas de usuários do Linux.

### **Estrutura dos Campos**

Cada linha representa um usuário e é dividida em **7 campos** separados por dois pontos (`:`):

`usuario:x:1000:1000:Nome do Usuario,/Local/Oficina,/Telefone:/home/usuario:/bin/bash`

1. **Nome de Usuário (_Username_):** O nome de login do usuário no sistema.
2. **Senha (_Password Placeholder_):** Historicamente continha a senha criptografada. Atualmente contém apenas um `x`, indicando que a senha real está armazenada de forma segura no `/etc/shadow`.
3. **UID (_User ID_):** Identificador numérico do usuário.
   - `0`: Reserva exclusiva do usuário **root** (superusuário).
   - `1 a 999`: Reservado para contas do sistema/serviços (ex: `www-data`, `nobody`).
   - `1000+`: Atribuído a usuários comuns.
4. **GID (_Group ID_):** Identificador numérico do grupo principal do usuário.
5. **GECOS / Informações de Comentário:** Informações adicionais do usuário (ex: nome completo, número de sala, telefone).
6. **Diretório Home (_Home Directory_):** O caminho do diretório pessoal do usuário (ex: `/home/isadora`).
7. **Shell Padrão (_Default Shell_):** O binário do interpretador de comandos executado no login (ex: `/bin/bash`, `/bin/zsh` ou `/sbin/nologin` para contas sem acesso interativo).

## 📌 2. O Arquivo `/etc/shadow` (Aula 35)

O arquivo `/etc/shadow` armazena de forma altamente segura as **senhas criptografadas** (com hash) e as **políticas de expiração de senha**. Diferente do `/etc/passwd`, a leitura deste arquivo é restrita exclusivamente ao usuário **root** (permissão `600` ou `400`).

### **Estrutura dos Campos**

Cada linha contém **9 campos** separados por dois pontos (`:`):

`usuario:$6$salt$hash:19800:0:90:7:14::`

1. **Nome de Usuário (_Username_):** Deve corresponder exatamente ao nome cadastrado no `/etc/passwd`.
2. **Senha Criptografada (_Encrypted Password_):**
   - Contém o algoritmo hash, o _salt_ e o hash da senha.
   - Prefixos de algoritmo comuns: `$1$` (MD5), `$5$` (SHA-256), `$6$` (SHA-512), `$y$` (yescrypt).
   - Se contiver `!` ou `*`, a conta está bloqueada/desativada.
3. **Data da Última Alteração:** Quantidade de dias desde **1º de Janeiro de 1970** (época Unix) em que a senha foi alterada pela última vez.
4. **Idade Mínima da Senha:** Mínimo de dias que o usuário deve esperar para poder alterar a senha novamente (`0` significa que pode alterar a qualquer momento).
5. **Idade Máxima da Senha:** Máximo de dias que a senha permanece válida antes de exigir troca.
6. **Período de Aviso de Expiração:** Número de dias antes do vencimento em que o sistema exibe avisos para o usuário trocar a senha.
7. **Período de Inatividade (_Grace Period_):** Dias após a expiração da senha em que a conta ainda aceita login e obriga a troca imediata antes de ser totalmente bloqueada.
8. **Data de Expiração da Conta:** Data exata (em dias Epoch desde 1970) em que a conta do usuário será desativada, independente do status da senha.
9. **Campo Reservado:** Reservado para uso futuro do sistema.

## 🛠️ Comandos Principais e Comparativos

| Arquivo           | Permissão de Leitura            | Propósito Principal                                     |
| :---------------- | :------------------------------ | :------------------------------------------------------ |
| **`/etc/passwd`** | Aberta para todos (`r--r--r--`) | Identificação do usuário, UID, GID, Home e Shell padrão |
| **`/etc/shadow`** | Restrita ao root (`-r--------`) | Hash das senhas e políticas de expiração de credenciais |

### **Comandos Úteis de Verificação**

- **`cat /etc/passwd`** ou **`getent passwd`**: Lista os usuários do sistema.
- **`sudo cat /etc/shadow`**: Exibe o arquivo de senhas (requer privilégios administrativos).
- **`chage -l <usuario>`**: Exibe o status e as regras de expiração da senha de um determinado usuário.
