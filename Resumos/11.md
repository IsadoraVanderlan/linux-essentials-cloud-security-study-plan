# Módulo 11: Gerenciamento de Processos e Sinais (Aula 43)

Este módulo aborda como o sistema operacional Linux gerencia a execução de programas através de **processos** e como podemos interagir com eles enviando **sinais** pelo terminal utilizando os comandos **`kill`** e **`killall`**.

---

## 📌 1. O que são Processos e PID?

No Linux, qualquer programa ou comando em execução é chamado de **processo**.

- **PID (_Process ID_):** Cada processo recebe do Kernel um número único de identificação.
- **PPID (_Parent Process ID_):** Identificador do processo pai que iniciou o processo atual.

---

## 📌 2. Como Localizar o PID de um Processo?

Antes de enviar qualquer sinal de encerramento com o `kill`, é necessário identificar o número do **PID**. Abaixo estão os principais comandos utilizados para essa busca:

### **1. `pgrep` (Busca Direta)**

Localiza e retorna apenas o número do PID com base no nome do processo.

```bash
pgrep nginx
```

### **2. `pidof` (Busca por Nome do Executável)**

Retorna os PIDs de um executável específico em execução.

```bash
pidof apache2
```

### **3. `ps aux | grep` (Detalhado) ou ps aux (Detalhado de todos programas ao mesmo tempo)**

Lista todos os processos do sistema e filtra pelo nome do programa. O **PID** é o **segundo valor** da linha (coluna ao lado do usuário).

```bash
ps aux | grep nginx
```

- **Exemplo de saída:**
  ```text
  USER         PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
  root        1234  0.0  0.1  10640  2200 ?        Ss   10:00   0:00 nginx: master
  ```

### **4. `top` / `htop` (Monitoramento em Tempo Real)**

Exibe uma interface interativa com os processos em execução. A primeira coluna mostra o **PID** correspondente.

```bash
top
```

---

## 📌 3. Entendendo os Sinais (_Signals_)

Sinais são mensagens assíncronas enviadas pelo sistema operacional ou pelo usuário para notificar ou alterar o comportamento de um processo.

### **Principais Sinais Utilizados:**

|    Sinal    | Número | Nome do Sinal | Descrição / Comportamento                                                                                                     |
| :---------: | :----: | :------------ | :---------------------------------------------------------------------------------------------------------------------------- |
| **SIGTERM** |  `15`  | _Termination_ | **Padrão.** Solicita o encerramento gracioso do processo, permitindo que ele salve dados e feche conexões antes de finalizar. |
| **SIGKILL** |  `9`   | _Kill_        | **Forçado.** Encerra o processo imediatamente de forma abrupta pelo Kernel. O processo não pode ignorar ou tratar este sinal. |
| **SIGHUP**  |  `1`   | _Hangup_      | Solicita o recarregamento dos arquivos de configuração de um serviço sem precisar reiniciá-lo.                                |
| **SIGINT**  |  `2`   | _Interrupt_   | Interrompe o processo via teclado (equivalente ao atalho `Ctrl + C`).                                                         |
| **SIGSTOP** |  `19`  | _Stop_        | Pausa temporariamente a execução do processo (sem encerrá-lo).                                                                |
| **SIGCONT** |  `18`  | _Continue_    | Retoma a execução de um processo que estava pausado pelo `SIGSTOP`.                                                           |

---

## 📌 4. Encerramento de Processos via PID (`kill`)

O comando `kill` é utilizado para enviar sinais a um processo específico **através do seu PID**.

### **Sintaxe Geral:**

```bash
kill -[SINAL] <PID>
```

### **Exemplos Práticos:**

```bash
# Envia o sinal padrão SIGTERM (15) para o processo com PID 1234
kill 1234

# Força o encerramento imediato (SIGKILL - 9) do processo com PID 1234
kill -9 1234
# ou
kill -SIGKILL 1234

# Solicita a recarga das configurações (SIGHUP - 1) do serviço com PID 5678
kill -1 5678
```

---

## 📌 5. Encerramento por Nome do Processo (`killall`)

O comando `killall` permite enviar sinais para todos os processos que correspondem ao **nome do programa**, sem a necessidade de buscar o PID individualmente.

### **Sintaxe Geral:**

```bash
killall -[SINAL] <nome_do_processo>
```

### **Exemplos Práticos:**

```bash
# Encerra suavemente todas as instâncias do navegador/serviço nginx
killall nginx

# Força o encerramento imediato de todas as instâncias do processo apache2
killall -9 apache2

# Pede confirmação interativa antes de encerrar cada processo
killall -i firefox
```

---

## 🛠️ Tabela Comparativa: `kill` vs `killall`

| Recurso           | `kill`                                 | `killall`                                     |
| :---------------- | :------------------------------------- | :-------------------------------------------- |
| **Identificador** | Requer o **PID** numérico (ex: `1234`) | Requer o **Nome** do programa (ex: `nginx`)   |
| **Escopo**        | Afeta apenas o processo específico     | Afeta **todas** as instâncias com aquele nome |
| **Sinal Padrão**  | `SIGTERM` (15)                         | `SIGTERM` (15)                                |

---

## 💡 Boas Práticas de Segurança e Dicas

- **Sempre comece com o sinal seguro:** Tente primeiro fechar o processo com `kill <PID>` (SIGTERM 15). Use a flag `-9` (SIGKILL) apenas se o processo estiver travado ou sem resposta, pois o encerramento forçado pode corromper dados não salvos.
- **Verificação Prévia:** Use comandos como `pgrep <nome>` ou `ps aux | grep <nome>` para confirmar o PID correto antes de enviar sinais de encerramento.
